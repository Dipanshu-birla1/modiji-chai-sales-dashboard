# Modiji Chai Sales — Before 2014

**A chai sales dashboard that probably takes its chai business a little too seriously.**

What started as a simple sales dashboard turned into a fictional chai business analytics project with a political satire twist. The idea is simple: explore chai sales, check which city is doing the most business, see who's on the VIP customer list, and investigate the legendary payment department.

Gujarat gets special attention here. Coincidence? The dashboard isn't answering that question.

**Important:** This is a parody project. All sales records, revenue figures, customer transactions, and payment categories are synthetic. The named public figures are used for satire, not as verified customers, funders, or evidence of real financial activity.

## What can you do with it?

- Check total revenue, orders, cups sold, and the top city.
- Filter sales by year, state, city, customer, and chai type.
- Compare city-wise and yearly revenue.
- See which chai type is supposedly running the show.
- Explore the VIP customer leaderboard.
- Check the two fictional payment categories: "PM CARES Fund" and "Chanda Chori".
- Search the transaction ledger and browse records page by page.
- Download filtered records as a CSV file.
- Inspect columns, data types, and missing values.

Basically, you can investigate the entire chai business without having to ask the chaiwala for his register.

## Run it locally

First, clone the repository:

```bash
git clone https://github.com/Dipanshu-birla1/modiji-chai-sales-dashboard.git
cd modiji-chai-sales-dashboard
```

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

Start the dashboard:

```bash
streamlit run main.py
```

The dashboard should open in your browser. If it doesn't, check the terminal before blaming the chai business.
